# Lab 17 - Proyecto final

## Objetivo

Elegir e integrar conscientemente las capacidades necesarias para resolver un problema pequeño. El valor del proyecto está en decidir qué usar y en implementarlo.

## Estado

⏳ Pendiente de implementación. Este README describe el alcance previsto; todavía no hay código ejecutable.

## Decisiones que debe permitir

| Necesidad | Decisión posible |
|---|---|
| Responder con conocimiento documental | Incorporar RAG |
| Ejecutar una operación concreta | Exponer una tool |
| Resolver pasos y bifurcaciones conocidos | Modelar un workflow |
| Decidir acciones iterativamente hacia un objetivo | Evaluar un agente y sus límites |
| Resolver el problema con pasos explícitos | Justificar que no hace falta un agente |
| Compartir capacidades entre aplicaciones | Evaluar MCP |

Son opciones que deben justificarse según el problema. No es obligatorio incorporar todas las tecnologías estudiadas ni usar un agente.

## Alcance previsto

```text
problema → capacidades justificadas → solución mínima → validación
```

- Definir un problema y criterios de aceptación.
- Elegir capacidades y documentar por qué aportan valor.
- Implementar una solución pequeña y comprensible.
- Verificar casos concretos y explicar limitaciones.

## Fuera de alcance

Una aplicación que acumule tecnologías para demostrar que fueron estudiadas. RAG, tools, workflow, agente y MCP conservan responsabilidades distintas; se combinan cuando la solución lo requiere.
