## Criterio de avance

Cada laboratorio debería contener, cuando se implemente:

- objetivo;
- concepto;
- problema que resuelve;
- implementación mínima;
- forma de ejecución;
- resultado esperado;
- relación con el laboratorio anterior;
- equivalencia conceptual con el proyecto Java.

La estructura inicial del repositorio contiene solamente los documentos y carpetas necesarias para comenzar.
