# Descanso del personal

La política ART-93821 regula vacaciones del personal. Cada empleado dispone de veinte jornadas pagas por año para recuperarse del trabajo. Puede repartirlas en dos períodos, acordando las fechas con su responsable. Para iniciar el trámite debe utilizar el portal de personas. Esta política corresponde a RRHH durante 2026. No regula licencias de software ni mantenimiento de equipos.
